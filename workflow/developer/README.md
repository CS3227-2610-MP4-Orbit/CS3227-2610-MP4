# Developer workflow package

This directory contains the tracked, role-specific process assets for the BugFlow Developer role.

- `context/` defines the bounded role and feature context supplied to agents.
- `skills/` contains reusable instructions for implementation, security, RBAC and verification reviews.
- `sdd/` contains the Developer feature SDD template used before implementation.
- `workflows/` describes the expected feature and handoff sequence.
- `reflection/` contains tracked observations about the development process and experiments.

Use `workflow/README.md` for the repository-wide workflow and `docs/DeveloperGuide.md` for the product and role implementation guide. Personal presentation notes remain in the ignored `docs/developer-agentic-se/` directory.
