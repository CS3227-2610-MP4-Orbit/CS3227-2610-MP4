# UI verification

1. Sign in as a Reporter. Check Home, My reports, and New report navigation at desktop and narrow widths; active state and keyboard focus should be clear.
2. Open a report. Use Details and Feedback links, including with a keyboard. Check the existing feedback and report content remain available.
3. Create and edit a Python snippet using Tab, Enter, undo, syntax highlighting and line numbers. Trigger a validation error in another field; confirm code remains. Save unchanged code and compare it to the original text.
4. Disable JavaScript or inspect the server-rendered form: the plain code field must still work. Do not run pasted code.
